# AI Proctoring System

## Overview

AI Proctoring System is a real-time computer vision based interview monitoring platform designed to detect suspicious behavior during online assessments and interviews.

The system uses YOLO object detection, gaze tracking, head pose estimation, behavioral analysis, and AI-powered event logging to monitor candidate activity.

This project is being built as a modular AI systems engineering project using Python, Streamlit, FastAPI, SQLite, and Computer Vision technologies.


## Features

* Real-time webcam monitoring
* YOLO-based object detection
* Multiple person detection
* Mobile phone detection
* Eye gaze tracking
* Head pose estimation
* Behavioral flagging system
* Event logging
* FastAPI backend
* SQLite database integration
* Streamlit dashboard
